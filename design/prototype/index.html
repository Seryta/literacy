① 1/8 · 用户协议 & 隐私确认

开始前，请家人代为确认

以下内容为使用本软件的必要条款，请家人读给使用者听，并代为勾选同意。

一我们如何服务

成人识字是一款陪伴成年朋友认识汉字、练习写字的工具。学习内容、语音讲解、书写评估默认都在手机本机处理，除了家人配置的在线教学服务外，不会主动收集或上传您的学习内容。

二说话与声音

为了通过说话与老师交流，软件需要使用手机的说话功能。只在学习页面打开，退出软件或回到桌面立即关闭。请家人和使用者特别放心：我们不采集、不保存任何声音录音文件，麦克风数据只在本机内存里做识别，识别完立刻释放，手机里和服务器上都找不到任何录音。您随时可以在手机系统设置中关闭这项权限。

三学习记录保存

您的姓名、学习进度、练习的字、写过的笔迹、家人配置的 API Key，都只保存在本手机的 App 私有目录里（加密或明文方式存储在系统分配的私有文件夹，其它 App 读不到），不会离开这台设备，代码里找不到任何会把这些数据主动上传到第三方的出口。卸载软件会同时清除这些记录，如有需要请提前备份。

四哪些信息会离开本机

使用者可以放心，学习过程中会联网的情况只有两种，全部由家人操作或配置：
① 家人配置的「AI 写字老师」：在您需要在线评估的时候，把您学字时的回答文字发送到家人选定的模型服务商；
② 第一次使用时下载离线语音包：直连国内 ModelScope 官方站点下载模型文件，不会携带任何个人信息。
除此之外没有其它的网络请求。

五家人协助配置

首次使用需要家人帮忙配置在线写字老师与下载语音包，两项都完成后才能开始学习。语音包下载后可离线使用；AI 写字老师是教学流程的必要配置，家人可在「设置」里更新其服务商、Key 或模型。

用户服务协议
本软件仅作为识字练习工具，不承担因用户误读或误写字导致的直接或间接损失。所有学习记录仅存储在用户的本机设备中，卸载软件即清空。

隐私政策 · 请家人重点查看
离开本机的只有两件事：① 你自己配置的 AI 老师会收到你在学字时说出的回答文字；② 下载离线语音包时直连国内 ModelScope 取模型文件。其它所有数据（姓名、学习进度、学习回答的本地评估、你的 API Key 本身）都只加密或明文保存在你手机 App 私有目录里，代码里找不到任何出口上传到第三方。

尤其放心：我们不采集、不保存你的任何声音录音文件，麦克风数据用完就在内存里释放了。

第三方开源声明
使用了业内成熟的开源组件：离线语音识别与合成（不用联网就能听到声音、识别说话，开源可审计）、本机数据库（所有字、写过的笔迹只存在自己手机里）、基础运行库、网络请求（家人配置教学服务或下载语音包时才会用到）等。相关许可证可在家人协助下通过「手机系统设置 - 应用 - 成人识字 - 开源声明」查看全文。
