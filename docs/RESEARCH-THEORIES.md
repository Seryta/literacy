# 教育理论调研

## 调研目标

为成人识字教学设计提供跨学科理论支撑。不局限于现有方案（费曼+间隔重复），主动搜索和吸收相关领域的最佳实践。

---

## 1. 成人学习理论（Andragogy）

### Malcolm Knowles 成人学习六原则

| 原则 | 对识字助手的含义 |
|------|-----------------|
| **需要知道为什么学** | 每个字要关联真实使用场景，不只是"这是第 3 课" |
| **自我概念** | 成年人不喜欢被当成学生对待，教学语气要平等 |
| **经验基础** | 利用已有生活经验做教学锚点，比如"这个'药'字你在药盒上见过" |
| **准备就绪** | 在用户有真实需求时教最有效，所以允许"插单"机制 |
| **问题中心（非内容中心）** | 围绕"我要能签自己的名字""我要看懂药盒"组织教学，而非"第一课学人，第二课学口" |
| **内在动机** | 外在奖惩（分数/排名）对成人效果差，要强调"现在你能自己看懂了" |

### 应用

- System Prompt 中的"关联生活"已体现部分原则
- 需要加强：**问题中心**——名字优先是好的，但可以推广为"任务包"模式（签字包/药盒包/门牌包/手机包）

## 2. 识字教学理论

### 2.1 整字教学 vs 部件教学

中文识字的两大流派：

| 流派 | 方法 | 优势 | 劣势 |
|------|------|------|------|
| **整字教学（Whole Character）** | 直接教整个字，用图片和场景联想 | 入门快，适合常用高频字 | 遇到生字不会拆 |
| **部件教学（Radical-based）** | 先教偏旁部首，再组合字 | 可迁移，"学会一个偏旁认一串字" | 入门慢，偏旁本身是抽象概念 |

### 对识字助手的设计影响

**混合策略**：
- 名字/高频生活字 → 整字教学（快速见效）
- 到一定字量后 → 引入部件教学（"你已经学了'口'和'马'，合起来就是'吗'"）
- 偏旁部首的教学排期：在学生掌握约 50 个基础字后开始引入

### 2.2 集中识字 vs 分散识字

| 流派 | 方法 | 适用场景 |
|------|------|---------|
| **集中识字** | 同类字一批学（一次学 5 个口字旁的字） | 需要字量基础 |
| **分散识字** | 在语境中随文识字（读句子时遇到新字顺便学） | 初学者更适合 |

**建议**：初级（前 100 字）用分散识字，中高级可引入集中识字。

### 2.3 注音识字（拼音辅助）

- 拼音是"拐杖"不是"腿"——帮助学生读出字音，但最终要撤除
- 不会拼音的成人学生可能占相当比例，需要**不依赖拼音的教学路径**
- 策略：默认不展示拼音，除非用户主动请求或连续失败

## 3. 技能习得理论

### 3.1 Dreyfus 技能习得模型

| 阶段 | 特征 | 教学策略 |
|------|------|---------|
| 新手 | 需要明确的规则和步骤 | 逐笔引导、固定流程 |
| 进阶新手 | 开始识别模式但需要指导 | 减少提示，鼓励自己尝试 |
| 胜任 | 能有意识地规划 | 独立书写、自主造句 |
| 精通 | 直觉性理解 | 阅读短句、场景应用 |
| 专家 | 创造性应用 | 不在首版范围 |

每个字的掌握过程就是一次 Dreyfus 模型的微型循环——从"需要完整引导"到"能独立写出"。

### 3.2 Fitts & Posner 三阶段模型

| 阶段 | 描述 | 对我们设计的启示 |
|------|------|----------------|
| 认知 | 理解任务是什么 | introduce + demonstrate 阶段 |
| 联结 | 练习并纠正错误 | guided_write + 即时反馈 |
| 自动化 | 不需有意识思考 | independent_write + 间隔复习 |

这个模型直接映射到我们的单字教学 9 阶段。

## 4. 认知负荷理论（Cognitive Load Theory）

### 核心概念

- **内在负荷**：任务本身的复杂度（写一个 15 画的字 > 写一个 3 画的字）
- **外来负荷**：无关信息造成的负担（花哨的 UI、多余的语音）
- **相关负荷**：有助于学习的认知投入（思考笔画之间的关系）

### 对识字助手的设计启示

- 一次只展示一个字，不堆砌信息（降低外来负荷）
- 米字格 + 灰色引导的设计已符合"给脚手架但不给答案"的原则
- 困难字拆成部件，分步教学（降低内在负荷）
- 不要在教学语音中插入无关社交语（"今天天气真好，我们来学……"）——每一句话都应有教学目的

## 5. 自我决定理论（Self-Determination Theory）

Ryan & Deci 的三个基本心理需求：

| 需求 | 对识字助手的设计影响 |
|------|---------------------|
| **自主性** | 用户可以随时说"换个字""先学点别的""今天不学了"——Agent 必须尊重 |
| **胜任感** | 每次 session 结束时必须有一次具体的成功体验——"今天你独立写出了'国'字" |
| **关联性** | 教学活动关联真实人际关系——"学完名字，你可以给女儿写贺卡" |

这三点已经在现有设计中有所体现（soft 优先、end_session 总结、people 表），但可以更系统化。

## 6. 多感官学习（Multisensory Learning）

| 感官通道 | 识字助手中的应用 |
|---------|----------------|
| 视觉 | 米字格、笔画动画、图片联想 |
| 听觉 | TTS 语音读出、拼音辅助 |
| 动觉 | 触屏手写 |
| 口语输出 | 费曼解释、造句（语音） |

四个通道全部覆盖。需要确保的是：对特定字，多种通道的信息是**一致的**——看了字形、听了读音、写了笔画、说了意思，四个通道指向同一个字。

## 7. 刻意练习（Deliberate Practice）

Ericsson 的刻意练习原则：

| 原则 | 对识字助手的设计影响 |
|------|---------------------|
| 有明确定义的目标 | 每个阶段有成功条件 |
| 即时反馈 | 笔画写完立即给出位置偏差反馈 |
| 挑战适中 | 支架式教学——刚好超出当前能力一点 |
| 重复并改进 | 间隔重复不只是重复，每次复习都应有新的要求（更快/更独立/更自信） |
| 关注错误 | 形近字辨析、常见错误记录和针对性练习 |

## 8. 理论整合：教学策略参考矩阵（初步）

以下矩阵将各理论的原则映射到具体的教学行为：

| 教学场景 | 涉及理论 | 教学行为 |
|---------|---------|---------|
| 引入新字 | 问题中心 / 认知负荷 / 多感官 | 先展示字，说一个生活场景，不展示拼音，给 2 秒等待用户反应 |
| 用户卡住 | 支架式 / 认知负荷 / 自主性 | 第一次卡：给拼音；第二次卡：拆字或给部件提示；第三次卡：主动问要不要跳过 |
| 用户学会 | 胜任感 / 刻意练习 | 独立写成功 → 记录结果 → 说一句具体的进步 |
| 复习旧字 | 间隔重复 / 提取练习 / 刻意练习 | 先让用户回忆（不看提示），再展示；用听音选字/听写而非闪卡 |
| 用户想换方向 | 自主性 / 准备就绪 | 接受"插单"，记录当前进度，切换后自然回到原主线 |
| 结束 session | 胜任感 / 内在动机 | 必须有一次可感知进步，总结具体能力（不是分数） |

## 9. 深挖方向

### 9.1 SLA 与中文作为第二语言的识字教学

中文对非母语学习者的研究对成人零基础识字有参考价值：

**关键发现**：
- **汉字识别遵循"整体优先"原则**：初学者先识别整体字形，再逐渐注意到内部结构。这支持"先整字后部件"的顺序
- **形音义三者不必同时教**：分开教再整合效果更好。例如先认字形+字义（看图识字），再加固字音关联
- **过度依赖拼音会延缓字形记忆**：拼音是"脚手架"，但需要在适当时候撤除。初学者会不自觉地只看拼音不看字——所以默认隐藏拼音是对的
- **笔画知识有助于长期记忆**：会笔顺的学生比不会的更不容易遗忘——所以跟写阶段不能跳过

**对我们设计的确认**：当前"字形→字义→字音"的分阶段引入策略符合 SLA 研究。

### 9.2 特殊教育领域的识字干预

阅读障碍（Dyslexia）和成人功能性文盲的干预研究：

**关键发现**：
- **多感官结构化语言教学（MSL/Orton-Gillingham 方法）**：同时使用视觉、听觉、触觉和动觉通道——每个字都要"看、说、写"三合一
- **明确、系统的语音意识训练**：把字音拆成最小的音素单位——与我们的"慢速分解朗读"一致
- **高频率、短时长 > 低频率、长时长**：每天 10 分钟比每周 1 小时效果好得多——支持 session 设计为 10-15 分钟
- **过度纠错会导致回避行为**：出错时先肯定尝试再温和纠正——已体现在 prompt 规则中
- **成功体验比准确率更重要**：每次 session 必须有一次明确成功——已体现在 end_session 规则中

**dapat 借鉴的**：
- "看、说、写"三位一体强制检查——如果一个字学生只看过没写过，不算学会
- 每天目标不是"学几个字"而是"完成几次成功体验"

### 9.3 小学语文教学大纲字序参考

国内小学语文（部编版）一年级字序（约 300 字）：

**字序规律**：
1. 先独体字后合体字（先学"人"再学"们"）
2. 先高频字后低频字（"的、一、是"在前）
3. 先易写字后难写字（笔画少的在前）
4. 按课文情境编排（"秋天"一课的系列字一起学）

**对成人识字的适用性**：
- 第 2 条（高频优先）和第 3 条（易写优先）完全适用
- 第 1 条（先独体后合体）部分适用——成人可以先学"妈"（常用合体字），再逐步理解"女"字旁
- 第 4 条（情境编排）适用——成人版情境："医院"主题（医/药/病/号/挂）比"秋天"主题更有意义

**建议**：高频字列表可以直接参考小学大纲，但编排主题要替换为成人生活场景。

### 9.4 中老年认知特点

针对 50+ 岁成人学习者的研究：

**关键发现**：
- **晶体智力（经验）保持良好，流体智力（速度）下降**——所以关联生活经验的教法特别有效，计时挑战特别无效
- **注意力持续时间 15-20 分钟**——单次 session 10-15 分钟是合适的
- **多任务处理能力下降**——一次只做一件事（已体现在规则中）
- **需要更多重复和巩固**——间隔重复的间隔可以比年轻人短一些（新学→当天→次日→3天→7天）
- **触屏手写接受度因人而异**——部分中老年用户可能因手抖或书写不惯而排斥。需要提供"识别优先"路径（多选、语音为主）作为替代
- **对机器语音的信任度**：自然、稳重的声音比年轻活泼的声音更受欢迎
- **学习动机高度具体**：不为"提升自我"，而为"能自己看懂药盒""能签字"——所以场景化教学特别重要
